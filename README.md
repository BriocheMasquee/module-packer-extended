# Module Packer Extended (MPX)

Community rebuild of [EncounterPlus Module Packer](https://github.com/encounterplus/module-packer), targeting the EncounterPlus V5 module format.

Status: beta. Core creation workflow is implemented and tested against real EncounterPlus imports:

- Create a module project, pages, groups, map/encounter references.
- Build a project into a `.module` archive ready for EncounterPlus.
- A Markdown preview that matches the real EncounterPlus rendering.
- A Compendium: items, spells, roll tables, and monsters.

Not yet on the VSCode Marketplace or packaged as a release — build from source. Legacy Module Packer / EncounterPlus V4 conversion is out of scope for now.
